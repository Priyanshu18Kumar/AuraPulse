# ✨ AuraPulse

> *"Where modern vision intelligence meets the timeless energy within."*

AuraPulse is an ethereal, AI-powered mindfulness interface that decodes your emotional presence, facial expression, and energetic resonance into radiant color frequencies and soul-stirring spiritual insights.

---

## 🔮 The Philosophy

We live in a world of constant motion, often forgetting to check in with the vibe we bring into the room. **AuraPulse** acts as a digital mirror for your inner frequency — bridging computer vision and spiritual intuition to reflect your aura, personality traits, and subtle energy states.

---

## 🌌 Key Highlights

- **⚡ Real-Time Aura Chromatics**: Captures your facial energy via camera and synthesizes a custom multi-layered canvas aura animation reflecting your color frequencies.
- **👁️ Vision Neural Analysis**: Powered by Gemini multimodal intelligence to evaluate facial resonance, spiritual insights, and authentic vibes — translated into expressive, soulful Hinglish.
- **✨ Energy Score & Archetypes**: Discovers your overall aura power level, unique value points, and anime-inspired spirit counterparts.
- **🧘 Dhyan & Ambient Meditation**: Immersive audio-visual breathing spaces designed to center your thoughts and restore calm.
- **📖 Soul Journal**: A private reflective sanctuary to note daily intentions, thoughts, and energetic shifts.
- **🌱 Lightweight & Privacy-First**: Client-side storage engineered with zero bloat and clean data management.

---

## 🛠️ Technology Canvas

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Motion (Framer Motion)
- **AI Engine**: Google Gemini API (`@google/genai`)
- **Graphics & Audio**: HTML5 Dynamic Canvas & Web Audio API
- **Icons**: Lucide Icons

---

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/aurapulse.git
   cd aurapulse
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env` file in the root directory:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Run development server**:
   ```bash
   npm run dev
   ```
